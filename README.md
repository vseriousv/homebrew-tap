# vseriousv/tap

Homebrew tap for my apps.

```sh
brew tap vseriousv/tap
brew trust vseriousv/tap          # Homebrew 7+ asks you to trust a third-party tap once
brew install --cask inero-movie
```

| Cask | What it is |
|---|---|
| `inero-movie` | [Inero Movie](https://github.com/vseriousv/inero-movie-releases): a reel editor that takes one idea to a published short video |
